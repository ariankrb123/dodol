# دودول | استخراج منوی کافه

برنامه Next.js برای خواندن صفحه عمومی منوی کافه، نمایش محصولات و دسته‌بندی‌ها و دریافت یک فایل Excel با دو برگه.

## اجرا

- Node.js 20 یا جدیدتر
- `npm install`
- `npm run dev`

برای استقرار، مخزن را به Vercel متصل کنید. برنامه دیتابیس یا متغیر محیطی لازم ندارد.

## خروجی Excel

- برگه «محصولات»: عنوان فارسی و انگلیسی، لینک عکس، قیمت، توضیحات و دسته‌بندی.
- برگه «دسته‌بندی‌ها»: عنوان، لینک تصویر و آیتم‌های مربوط.

عکس‌ها در فایل به صورت لینک ثبت می‌شوند؛ فایل تصویر درون workbook جاسازی نمی‌شود.

## استخراج

اسکرپر ساختارهای رایج HTML، داده‌های Schema.org، WooCommerce Store API و انواع محتوای عمومی وردپرس برای محصول/منو را بررسی می‌کند. برای منوهای وردپرسی که فقط با JavaScript بارگذاری می‌شوند یا API عمومی ندارند، ممکن است نیاز به پشتیبانی اختصاصی باشد. سایت مقصد باید از سرور Vercel قابل دسترسی باشد.
