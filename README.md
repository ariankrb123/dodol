# دودول | استخراج منوی کافه

برنامه‌ای با Next.js برای دریافت لینک عمومی منوی کافه، استخراج محصولات و دسته‌بندی‌ها، پیش‌نمایش و دانلود JSON، و انتقال به API منوتام.

## اجرا

- Node.js 20 یا جدیدتر
- `npm install`
- `cp .env.example .env.local` و تکمیل تنظیمات
- `npm run dev`

در Vercel هم همین متغیرهای محیطی را در تنظیمات پروژه وارد کنید. نیازی به دیتابیس نیست؛ منوی استخراج‌شده در صفحه نگه داشته می‌شود و با «ذخیره فایل JSON» روی دستگاه کاربر دانلود می‌شود.

## تنظیم دریافت توکن

توکن در سمت سرور و برای هر بار ارسال تازه از `MENU_TOKEN_URL` گرفته می‌شود. برنامه این موارد را می‌خواند: `access_token`، `token`، `data.access_token` یا `data.token`. درخواست پیش‌فرض JSON شامل `client_id` و `client_secret` است.

اگر سرویس توکن قالب دیگری می‌خواهد، `MENU_TOKEN_BODY` را به صورت JSON تنظیم کنید. برای نمونه:

```json
{"grant_type":"client_credentials","client_id":"...","client_secret":"..."}
```

مقادیر حساس فقط در سرور هستند و نباید با پیشوند `NEXT_PUBLIC_` تعریف شوند. `MENU_API_URL` به صورت پیش‌فرض روی `https://menutam.ir/api/v1/public/menu` است.

## انتقال به منوتام

در هر ارسال، ابتدا توکن تازه دریافت می‌شود و سپس یک درخواست `POST` با `Authorization: Bearer <token>` فرستاده می‌شود. بدنه فعلی:

```json
{
  "source": "https://cafe.example/menu",
  "categories": [{"title":"اسپرسو","image":"https://...","items":["اسپرسو"]}],
  "products": [{"name":"اسپرسو","englishName":"","description":"...","price":"...","image":"https://...","category":"گرم"}]
}
```

برای موفقیت، مقصد باید پاسخ HTTP موفق بدهد. اگر پاسخ شامل `imported_count` یا `data.imported_count` باشد، تعداد با کل محصولات و دسته‌ها مقایسه می‌شود. برای تطبیق دقیق‌تر با API منوتام، قالب مورد انتظار سرویس توکن، نام فیلدهای بدنه، و قالب تأییدیه مقصد باید با قرارداد واقعی API هماهنگ شود؛ endpoint عمومی ارائه‌شده بدون توکن پاسخ ۴۰۱ می‌دهد و مستندات API/آدرس صدور توکن همراه درخواست نبود.

## استخراج

اسکرپر JSON-LD (Product/Menu) و چند ساختار رایج HTML را می‌خواند. سایت‌هایی که منو را صرفاً با JavaScript سمت مرورگر می‌سازند ممکن است به پشتیبانی اختصاصی نیاز داشته باشند. تصاویر به شکل URL اصلی ذخیره می‌شوند؛ فایل تصویر به هاست دانلود نمی‌شود.
